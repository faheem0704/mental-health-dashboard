# 🧠 Post-COVID Mental Health Dashboard

This interactive dashboard visualizes global suicide trends by age and gender using WHO data, and explores correlations from a mental health survey among tech workers.

🌐 **Live Demo**: [Click to View Dashboard](https://YOUR-APP-LINK.streamlit.app)

---

## 📊 Features

- 🔎 Filter suicide rates by gender and age group
- 🌍 View top 10 countries by suicide rate
- 📋 Correlation heatmap of survey responses
- 🧼 Clean, minimal dark UI using Streamlit & Plotly

---

## 📁 Dataset Sources

- [Mental Health in Tech Survey (Kaggle)](https://www.kaggle.com/datasets/osmi/mental-health-in-tech-survey)
- [Global Suicide Rates (WHO)](https://www.kaggle.com/datasets/twinkle0705/mental-health-and-suicide-rates)
